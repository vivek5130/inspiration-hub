## Agent Building Blocks

- **[Browser Use](https://github.com/browser-use/browser-use)** – Python library that lets AI agents control a web browser like a person.
- **[claude-mem](https://github.com/thedotmack/claude-mem)** – Gives coding agents memory across sessions by capturing and compressing what they did.
- **[CrewAI](https://github.com/crewAIInc/crewAI)** – Framework for teams of role-playing AI agents that work together on tasks.
- **[Dify](https://github.com/langgenius/dify)** – Visual platform for building AI workflows, RAG pipelines and agents.
- **[Langflow](https://github.com/langflow-ai/langflow)** – Drag-and-drop builder for AI agents and workflows.
- **[Langfuse](https://github.com/langfuse/langfuse)** – Tracing, evaluation and monitoring for LLM apps and agents.
- **[LangGraph](https://github.com/langchain-ai/langgraph)** – Build reliable agents as graphs of steps, with memory and human checkpoints.
- **[MCP Servers](https://github.com/modelcontextprotocol/servers)** – Reference servers for the Model Context Protocol, the standard way to connect AI to tools and data.
- **[Mem0](https://github.com/mem0ai/mem0)** – Memory layer that lets AI apps and agents remember users over time.
- **[Promptfoo](https://github.com/promptfoo/promptfoo)** – Test and red-team prompts, agents and RAG systems before shipping.
- **[smolagents](https://github.com/huggingface/smolagents)** – Hugging Face's tiny library for agents that act by writing code.
- **[Superpowers](https://github.com/obra/superpowers)** – Skills framework and development method that makes coding agents work more reliably.

## Agents & Assistants

- **[AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)** – One of the first autonomous AI agent projects, now a platform for building and running agents.
- **[Goose](https://github.com/aaif-goose/goose)** – Extensible open-source agent that can install, run, edit and test things on your machine.
- **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** – Nous Research's open-source personal agent that learns and improves as you use it.
- **[Open Interpreter](https://github.com/openinterpreter/openinterpreter)** – Lets language models run code on your computer; now a coding agent for open models.
- **[OpenClaw](https://github.com/openclaw/openclaw)** – Hugely popular open-source personal AI agent that runs on your own devices and actually does tasks for you.

## Coding Agents

- **[Aider](https://github.com/Aider-AI/aider)** – AI pair programmer in your terminal that edits code in your Git repo.
- **[Codex CLI](https://github.com/openai/codex)** – OpenAI's lightweight open-source coding agent for the terminal.
- **[Gemini CLI](https://github.com/google-gemini/gemini-cli)** – Google's open-source agent that brings Gemini into your terminal.
- **[OpenHands](https://github.com/OpenHands/OpenHands)** – Open-source AI software developer that writes code, runs commands and browses the web.
- **[SWE-agent](https://github.com/SWE-agent/SWE-agent)** – Research agent that takes a GitHub issue and tries to fix it automatically.

## Image & Video

- **[ComfyUI](https://github.com/Comfy-Org/ComfyUI)** – Node-based interface for building image and video generation pipelines.
- **[Stable Diffusion web UI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)** – Popular browser interface for running Stable Diffusion image models locally.

## Learn by Building

- **[llm.c](https://github.com/karpathy/llm.c)** – Andrej Karpathy's LLM training written in plain C and CUDA, with no frameworks.
- **[micrograd](https://github.com/karpathy/micrograd)** – A tiny autograd engine; the clearest way to understand how backpropagation works.
- **[nanochat](https://github.com/karpathy/nanochat)** – Train, fine-tune and chat with your own small ChatGPT-style model for about $100.
- **[nanoGPT](https://github.com/karpathy/nanoGPT)** – The simplest, fastest code for training and fine-tuning GPT models.
- **[tinygrad](https://github.com/tinygrad/tinygrad)** – A small, hackable deep learning framework between micrograd and PyTorch.

## Robotics & Simulation

- **[Genesis](https://github.com/Genesis-Embodied-AI/genesis-world)** – Fast physics simulation platform for training robots and embodied AI.
- **[Gymnasium](https://github.com/Farama-Foundation/Gymnasium)** – The standard set of environments for reinforcement learning experiments.
- **[LeRobot](https://github.com/huggingface/lerobot)** – Hugging Face's open models, datasets and tools for real-world robot learning.
- **[openpi](https://github.com/Physical-Intelligence/openpi)** – Physical Intelligence's open robot foundation models (the π models) and code.

## Run AI Locally

- **[llama.cpp](https://github.com/ggml-org/llama.cpp)** – Run LLMs efficiently on regular CPUs and GPUs; the engine behind many local AI apps.
- **[MLX](https://github.com/ml-explore/mlx)** – Apple's framework for running and training models fast on Apple silicon Macs.
- **[Ollama](https://github.com/ollama/ollama)** – The easiest way to download and run open models on your own computer.
- **[Open WebUI](https://github.com/open-webui/open-webui)** – Self-hosted ChatGPT-style interface for local and cloud models.
- **[Unsloth](https://github.com/unslothai/unsloth)** – Fine-tune and run open models faster and with much less memory.
- **[vLLM](https://github.com/vllm-project/vllm)** – High-throughput engine for serving LLMs in production.
- **[whisper.cpp](https://github.com/ggml-org/whisper.cpp)** – Fast local speech-to-text using OpenAI's Whisper models.

## Science & Research

- **[The AI Scientist](https://github.com/SakanaAI/AI-Scientist)** – Sakana AI's system that generates research ideas, runs experiments and writes papers.
