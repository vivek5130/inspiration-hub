## Frameworks & Libraries

- **[DSPy](https://github.com/stanfordnlp/dspy)** – Program LLM pipelines in Python and let the framework optimize the prompts.
- **[Hugging Face Transformers](https://github.com/huggingface/transformers)** – The standard library for loading and using thousands of pretrained models.
- **[JAX](https://docs.jax.dev)** – Google's high-performance numerical computing library for machine learning research.
- **[Keras](https://keras.io)** – Beginner-friendly deep learning API that runs on JAX, PyTorch or TensorFlow.
- **[LangChain](https://github.com/langchain-ai/langchain)** – Popular framework for building LLM apps and agents from reusable pieces.
- **[LlamaIndex](https://github.com/run-llama/llama_index)** – Framework for connecting LLMs to your own documents and data.
- **[Pydantic AI](https://github.com/pydantic/pydantic-ai)** – Type-safe Python framework for building AI agents.
- **[PyTorch](https://pytorch.org)** – The most widely used deep learning framework for research and production.
- **[scikit-learn](https://scikit-learn.org/stable/)** – Classic machine learning in Python: classification, regression, clustering and more.
- **[TensorFlow](https://www.tensorflow.org)** – Google's end-to-end machine learning platform.

## Leaderboards & Benchmarks

- **[Artificial Analysis](https://artificialanalysis.ai)** – Compares models and API providers on quality, speed and price.
- **[Epoch AI](https://epoch.ai)** – Research and data on AI trends: compute, model sizes, costs and benchmarks.
- **[LMArena](https://lmarena.ai)** – Ranks models by real people voting on side-by-side answers.
- **[SWE-bench](https://www.swebench.com)** – Leaderboard for how well AI can fix real GitHub issues.

## Open-Weight Models

- **[DeepSeek](https://huggingface.co/deepseek-ai)** – DeepSeek's open models, including its V and R1 reasoning series.
- **[Gemma](https://deepmind.google/models/gemma/)** – Google DeepMind's lightweight open models built from Gemini research.
- **[gpt-oss](https://github.com/openai/gpt-oss)** – OpenAI's open-weight reasoning models.
- **[Kimi](https://huggingface.co/moonshotai)** – Moonshot AI's open models, known for long context and agentic tasks.
- **[Llama](https://www.llama.com)** – Meta's family of open-weight models.
- **[Mistral](https://huggingface.co/mistralai)** – Mistral AI's open models, from small to Mixture of Experts.
- **[Qwen](https://huggingface.co/Qwen)** – Alibaba's open models for text, code, vision and audio.

## Platforms & APIs

- **[Claude Platform Docs](https://docs.anthropic.com)** – Anthropic's documentation and API for building with Claude models.
- **[Fireworks AI](https://fireworks.ai)** – Fast inference and fine-tuning for open models.
- **[Google AI Studio](https://aistudio.google.com)** – Try and build with Gemini models in the browser, then get an API key.
- **[Hugging Face](https://huggingface.co)** – Hub for open models, datasets and demos, plus popular ML libraries.
- **[OpenAI Platform](https://platform.openai.com)** – OpenAI's API, playground and docs for GPT models.
- **[OpenRouter](https://openrouter.ai)** – One API to access hundreds of models from many providers.
- **[Together AI](https://www.together.ai)** – Cloud for running, fine-tuning and training open models.

## Vector Databases

- **[Chroma](https://www.trychroma.com)** – Open-source, easy-to-start embedding database for AI apps.
- **[pgvector](https://github.com/pgvector/pgvector)** – Adds vector similarity search to PostgreSQL.
- **[Pinecone](https://www.pinecone.io)** – Managed vector database for search and RAG at scale.
- **[Qdrant](https://qdrant.tech)** – Fast open-source vector search engine written in Rust.
- **[Weaviate](https://weaviate.io)** – Open-source vector database with built-in hybrid search.
