## Font Libraries

- **[Adobe Fonts](https://fonts.adobe.com)** – Thousands of high-quality fonts included with Creative Cloud.
- **[Fontshare](https://www.fontshare.com)** – Free, quality fonts from the Indian Type Foundry.
- **[Google Fonts](https://fonts.google.com)** – Free, open-source font library with easy web embedding.
- **[Inter](https://rsms.me/inter/)** – Popular open-source typeface designed for computer screens.
- **[Velvetyne](https://velvetyne.fr)** – Experimental, open-source fonts from an independent foundry.

## Guides

- **[Butterick's Practical Typography](https://practicaltypography.com)** – Clear, practical rules for better-looking text.
- **[The Elements of Typographic Style Applied to the Web](https://webtypography.net)** – Classic typography principles translated to HTML and CSS.

## Inspiration & Pairing

- **[Fontpair](https://www.fontpair.co)** – Ready-made Google Font pairings for headings and body text.
- **[Fonts In Use](https://fontsinuse.com)** – Archive of real-world typography, searchable by typeface.
- **[Typewolf](https://www.typewolf.com)** – Trending fonts, pairings and type recommendations from real websites.

## Tools

- **[Modern Font Stacks](https://modernfontstacks.com)** – Ready-to-use system font stacks that load instantly.
- **[Typescale](https://typescale.com)** – Generate a balanced set of font sizes and the CSS for it.
