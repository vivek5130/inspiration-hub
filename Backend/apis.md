- **[Google API Design Guide](https://cloud.google.com/apis/design)** – Google's rules for designing consistent, resource-oriented APIs.
- **[GraphQL](https://graphql.org/learn/)** – Official guide to GraphQL, a query language that lets clients ask for exactly the data they need.
- **[gRPC](https://grpc.io)** – High-performance framework for service-to-service calls using Protocol Buffers.
- **[Hoppscotch](https://hoppscotch.io)** – Open-source, browser-based tool for testing APIs.
- **[JSON:API](https://jsonapi.org)** – A shared standard for structuring JSON API requests and responses.
- **[Microsoft REST API Guidelines](https://github.com/microsoft/api-guidelines)** – Microsoft's detailed conventions for REST APIs.
- **[OpenAPI Specification](https://www.openapis.org)** – The standard format for describing REST APIs, used for docs and code generation.
- **[RFC 9457: Problem Details for HTTP APIs](https://www.rfc-editor.org/rfc/rfc9457)** – The standard way to return error details from an HTTP API.
- **[Stripe API Reference](https://docs.stripe.com/api)** – Widely admired as a model of clear, consistent API design and docs.
- **[Zalando RESTful API Guidelines](https://opensource.zalando.com/restful-api-guidelines/)** – Practical, well-explained REST and event guidelines from Zalando.
