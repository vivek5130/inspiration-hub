## 3D

- **[Blender](https://www.blender.org)** – Free, open-source 3D software for modeling, animation and rendering.
- **[React Three Fiber](https://r3f.docs.pmnd.rs)** – Build Three.js scenes with React components.
- **[Spline](https://spline.design)** – Design interactive 3D scenes in the browser and embed them on websites.
- **[Three.js](https://threejs.org)** – The most popular JavaScript library for 3D on the web.
- **[Three.js Journey](https://threejs-journey.com)** – Bruno Simon's in-depth course on creating 3D websites.

## Animation

- **[GSAP](https://gsap.com)** – Powerful JavaScript animation library behind many award-winning sites.
- **[LottieFiles](https://lottiefiles.com)** – Lightweight animations you can drop into websites and apps.
- **[Motion](https://motion.dev)** – Animation library for React and JavaScript (formerly Framer Motion).

## Inspiration & Learning

- **[Codrops](https://tympanus.net/codrops/)** – Creative web tutorials and experiments with animation, WebGL and CSS.

## Shaders

- **[Shadertoy](https://www.shadertoy.com)** – Community for creating and sharing real-time GPU shaders.
- **[The Book of Shaders](https://thebookofshaders.com)** – Gentle, step-by-step guide to writing fragment shaders.
